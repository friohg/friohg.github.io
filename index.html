🤔 What Is cachellm?

cachellm is a smart caching proxy that sits between your application and any OpenAI-compatible LLM API. Think of it as a middleman that remembers every answer. Once it sees a question before, it hands back the saved answer—instantly. No need to call theexpensive API again.

It is built for developers using AI agents (like AutoGPT, LangChain, or custom tools) who want to dramatically reduce their monthly LLM bills. But you don't need to be a developer to benefit—if you run any AI tool that talks to OpenAI, cachelllm can help.

The "local-first" part means everything runs on your own computer. Your data stays private. The caching database is stored asa simple SQLite file on your disk. Nocloud, no third-party servers. Ever.

✨ Key Features

🎯 Exact Caching

If the exact same request is made twice, the second one is served instantly from the local database. Zero API call, zerocost, zerolatency.

🧠 Semantic Caching

Similar questions? No problem. If you ask "What's the weather?" and then "Tell me the weather today," cachelllm recognizes they're semantically equivalent. It returns the cached answer without calling the API.

🔧 Tool-Result Caching

AI agents often call tools (like calculators, search, or databases)). cachelllm caches those results too. Repeated tool calls are instant and free.

🚦 Request Coalescing

When multiple identical requests arrive simultaneously, cachelllm merges them into asingle API call. Everyone gets the same fast response. You pay once.

🔄 How It Works

The concept is beautifully simple:

  1. Install cachelllm on your Windows machine.
  2. Set your app's API base URL to http://localhost:8000/v1
  3. Use your app as normal. cachelllml intercepts every request.
  4. For new requests, it forwards them to thereal API (like OpenAI), retrieves the answer, storesit locally, then sends it back.
  5. For repeated/similar requests, it returns the saved answer immediately. No API call is made.

🔑 Key point: You bridge works with any OpenAI-compatible API—OpenAI, Azure OpenAI, LocalAI, Ollama, Together AI, anysimilar service.
